# SPC4004: Language Assessment - Dataset Files
This repository contains the dataset files used for my SPC4004 Assessment 3 submission, “Language Assessment”. The project explores the uses of “man” in a sample from the London English Corpus. The PDF report submitted on QMPlus refers to this repository for the dataset.

## Files

### Initial Dataset File ('Initial Dataset.csv')
This file contains the initial sample exported from Sketch Engine. Profanity was removed at the extraction stage in Sketch Engine before the file was saved.

### Filtered Dataset File ('Filtered Dataset.csv')
This file contains the dataset after manual filtering. Sentences with unclear uses of “man”, along with any non-comparable or repeated items, were removed to create a cleaner dataset for classification.

### Final Results File ('Final Dataset Results.csv')
This file contains the final classified dataset used for the graph and analysis in the report. It includes the final labels assigned to each remaining sentence after manual checking and revision.

## Notes
The dataset was manually reviewed as part of the assignment workflow. AI was used to suggest category labels and sentence-level classifications, but the final labels were checked and revised manually before analysis.
